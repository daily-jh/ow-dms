## Phase 1에서 완료한 것
- 합성 A/B기관·직무별 계정·가상 후원자·후원금·쌀 100포 입고와 30/20/15포 배분 seed
- 로그인(개발용 합성 계정) → 초안 → 승인요청 → 승인(원장·잔고·outbox 한 트랜잭션) → 재고 → 문서 미리보기
- 배분: 초안 → 승인(예약) → 출고 반영(원장 차감), 동시 출고 시 행 잠금으로 음수재고 차단
- 문서: 인수증·배분명부·후원금 수입확인(공통 예시), 스냅샷·템플릿버전·해시 고정 재출력
- 희망이음: reference 어댑터, 내부 검토 Excel(호환 미검증 표기), submit 비활성
- 기관 격리: RLS(FORCE)·복합 FK·트랜잭션 범위 컨텍스트, worker도 기관 컨텍스트로 처리
- 시험: 단위 23 + 실제 PostgreSQL 통합/API 28 + 브라우저 수직 점검 1 (VERIFICATION_LOG 참조)
