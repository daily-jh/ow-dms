## 개발 중 내린 확인 필요 가정
- 기간 마감 단위는 월(`YYYY-MM`)로 가정.
- 문서 자동생성(승인 시 인수증·배분명부·후원금 확인)은 내부용이며 기관 결재 문서를 대체하지 않는다.
- 접속기록 보관기간(제안 2년)은 아직 정책 테이블로 구현하지 않았다.
