# 희망이음 Excel 업로드 근거대장 (HOPE_EUM_EXCEL_EVIDENCE)

기준: 「OW-DMS → 희망이음 Excel 업로드 연계 근거분석·개발명세」(2026-10-30). 이 문서는 업로드 호환성 인증서가 아니다.
코드 위치: `packages/adapters/src/hopeEumGuide.ts`, 화면 `/integrations`(희망이음 준비), API `GET /v1/integrations/hope-eum-guide`.

## 1. 확인 수준

| 주장 | 판정 | 근거 |
|---|---|---|
| 후원품 수입은 양식다운로드 → 작성 → 업로드 → 저장 절차로 Excel 등록 | 확인 | B-01 사례집 인쇄 19쪽 Q8 |
| 후원품 수입 Excel 작성항목 9개 | 확인(논리 항목) | B-01 |
| 후원품 유형 `01`~`08`, 지정 `0`/비지정 `1` | 사례집 기준 확인, 현행 재확인 필요(HV-03) | B-01 |
| 원본 시트명·열 순서·데이터 시작행·숨김셀·데이터검증 | 미확인 | 원본 미확보(HV-01) |
| 후원금 정기·비정기입금 Excel 일괄 업로드 지원 | 미확인 | 업무 화면 존재만 확인(A-02) |
| 후원품 사용 Excel 업로드 | 미확인 | "수입내역 가져오기"는 화면 기능(B-03) |
| 후원자·결연자 일괄 등록 Excel | 미확인 | 등록 화면만 확인(B-03) |

B-01: 『비영리 실무자를 위한 Q&A 사례집』(톡톡톡) https://www.acrc.go.kr/boardDownload.es?bid=99&list_no=84266&seq=1 — 2023/2024 자료 인용, 2026 원본 Excel 규격 아님.

## 2. 후원품 수입 9개 항목 ↔ OW-DMS (내부 대조표 `9항목대조` 시트)

열 순서는 사례집 항목 순서이며 희망이음 원본의 열 순서가 아니다.

| 순번 | 희망이음 항목 | OW-DMS 값 | 지금 처리 |
|---|---|---|---|
| 1 | 후원품 유형 | 후원처·기탁 성격 | 비움 + `UNMAPPED_GOODS_TYPE`. 자동 추정 금지(03·04·08 자동 지정 금지) |
| 2 | 후원품 종류 | 품목 | 비움 + `UNMAPPED_ITEM_KIND_OR_UNIT`. 기관 기초코드 필요(HV-02) |
| 3 | 내역 | 담당자 작성 | 비움. 입고 메모는 개인정보 위험으로 옮기지 않음 |
| 4 | 품명 | `goods_receipt_lines` 품목명 | 채움 |
| 5 | 단위 | 입고 행 단위 | 채움. 기관 등록 단위와 대조 필요 |
| 6 | 수량 | 입고 행 수량 | 채움(문자열 셀) |
| 7 | 단가 | `unit_value` | 채움. 가액 미확정이면 `UNVERIFIED_VALUATION` |
| 8 | 금액 | `total_value` | 채움. 수량×단가 bigint 검산, 불일치 시 `AMOUNT_SUM_MISMATCH` |
| 9 | 지정구분 | 기탁 조건 | 비움 + `UNKNOWN_GIFT_DESIGNATION`(입고에 지정 정보 없음) |

배치 안에 후원자·수입일이 다른 건이 섞이면 모든 행에 `MIXED_DONOR_OR_DATE`(사례집에서 후원자·수입일을 화면에서 지정하므로 따로 올림).
코드·수량·금액 셀은 텍스트 서식(`@`)으로 저장해 `01`이 `1`로 바뀌지 않게 한다. 수식 시작문자는 `'`로 막는다.

## 3. 이번에 반영하지 않은 것(명세 Phase A 중 후속)

DB 변경이 필요해 별도 작업으로 남긴다. 운영 데이터·외부 전송 변경 없음.
- 원본 Excel 업로드·구조분석·SHA256 버전관리(`TemplateProfile`, 8.2 상태)
- 기관·업무·연도별 코드 매핑 UI와 미매핑 목록(희망이음 후원자·결연자 외부번호 포함)
- 업로드 결과 수동 확인(`UPLOADED_UNCONFIRMED`·`VERIFIED` 증빙) 기록
- 후원금 정기·비정기 논리필드 내부 대조

## 4. 희망이음 고객센터 확인 질문(1566-3232)

1. 후원금 정기입금·비정기입금 메뉴에 Excel 일괄등록이 있는지, 원본은 어디서 받는지
2. 후원품 수입관리의 현재 Excel 원본·작성 지침과 기관별 기초코드 목록
3. 후원품 사용관리에 외부 Excel 업로드가 있는지
4. 후원자·결연자 일괄등록 가능 여부와 외부 번호 연결 필드
5. 후원품 Excel 한 파일에 후원자·수입일이 다른 건을 섞을 수 있는지
6. 업로드 결과의 행별 성공·실패·등록번호를 조회하거나 내려받을 수 있는지
7. 법인·시설 회계 귀속과 연도전환 시 계정 매핑
8. 개발사가 만든 Excel을 기관 담당자가 직접 올리는 방식에 제약이 있는지

답변은 일시·담당자·질문·근거를 `VALIDATION_REGISTER.md` HV 항목에 기록한다.
